Detailed Description

template<typename ScalarType, bool full>
class argon::vectorize::Step< ScalarType, full >

One step of vectorize::for_each: the elements [index(), index() + count()) of the range.

Template Parameters
ScalarTypeThe lane type the loop is written in.
fullWhether every lane is in range. On NEON the loop body is instantiated with full steps for the whole vectors (plain loads and stores) and once more with a partial step for the tail; on MVE every step is predicated, which is what lets the compiler drop the predication into the loop instructions (dlstp/letp).
