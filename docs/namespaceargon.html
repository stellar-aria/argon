Detailed Description

A 128-bit SIMD vector wrapping a scalar type, providing arithmetic, logical, and data-movement operations.

Template Parameters
ScalarTypeThe element type (e.g., int32_t, float, uint8_t).

Inherits all lane-wise operations from argon::Vector and adds 128-bit-specific operations such as narrowing, widening multiplies, cross-half operations, reductions, and (optionally) AES acceleration. Use ArgonHalf<ScalarType> for the 64-bit sibling.

Returns
The new vector
Warning
This function does not short-circuit. It will evaluate both branches regardless of the condition. Due to the way the NEON pipeline works (i.e. without conditional execution flags the way that VFP has), we're required to execute both branches of the conditional and then select the lanes we want, even if one of the branches is completely unused.

Selects by a mask vector (all ones / all zeros per lane), e.g. from Predicate::ToMask().
