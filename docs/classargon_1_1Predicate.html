Detailed Description

template<typename VectorType>
class argon::Predicate< VectorType >

A per-lane boolean for vectors of type VectorType, as returned by comparisons.

Template Parameters
VectorTypeThe vector type the predicate applies to (e.g., int32x4_t, float32x4_t).

On NEON a predicate is a mask vector, with every bit of a lane set when the lane is active. On MVE it is an mve_pred16_t, with one bit per byte of the vector, so a 32-bit lane owns four bits. The interface is the same on both, so code written against it is portable; use ToMask() where a mask vector is genuinely needed.
