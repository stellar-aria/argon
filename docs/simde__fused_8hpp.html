Detailed Description

The single-precision fused multiply-add of the VFPv4 layer, for SIMDe on a host with FMA.

SIMDe's vfma/vfms on x86 are a multiply and an add, with two roundings, so the fused forms go lane by lane through std::fma, which a host compiled with FMA lowers to one fused instruction. arm_simd/neon/vfpv4.hpp is not used here: it declares half-precision forms SIMDe lacks.
