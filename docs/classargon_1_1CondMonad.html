Detailed Description

template<typename VectorType, typename ValueType>
requires (ValueType::lanes == Predicate<VectorType>::lanes)
class argon::CondMonad< VectorType, ValueType >

The result of if_(...) and each else_if_(...): a value chosen per lane by a chain of conditions.

Template Parameters
VectorTypeThe vector type the conditions were computed from.
ValueTypeThe Argon type of the values being chosen.

Lanes take the value of the first condition that holds for them, as in an if / else-if chain; else_ supplies the value for lanes where none held and ends the chain. Every branch is evaluated (see ternary).
