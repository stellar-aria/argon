Detailed Description

template<typename PointerType, size_t Stride>
struct argon::vectorize::detail::TailCursor< PointerType, Stride >

Shared position-keeping for the tail iterators.

Positions count lanes (frames, for interleaved views) rather than holding a pointer, so the iterator never forms a pointer past the end of the range.
