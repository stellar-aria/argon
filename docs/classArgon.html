The next lanes indices of a forward walk through a circular buffer of size elements.

Each lane takes offset, then offset advances by step, wrapping to 0 when it reaches size. offset is left at the index after the last lane. As with the instruction, offset and size should be multiples of step with offset < size; otherwise the index never equals size, and never wraps. MVE: viwdup.

step1, 2, 4 or 8.
